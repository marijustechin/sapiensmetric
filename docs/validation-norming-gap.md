# Validation & norming gap analysis — Sapiens Metric

Status: draft discovery baseline (T-001).

## Purpose

State what is missing before reliability, validity, and representative norms
can be claimed, and what each gap implies for permitted claims (see
`docs/claims-ladder.md`).

## Current state

Sapiens Metric has **no** psychometric data: no item pool, no administration
data, no reliability estimates, no validity evidence, and no normative sample.
Every tier of claim above Tier 0 (T-001) therefore remains blocked.

## Gap 1 — Item pool and item-level evidence

Missing:

- An authored, versioned item pool with documented rules and provenance.
- Item difficulty/quality data (no administrations exist).

Implication: no instrument to validate, no item statistics.

## Gap 2 — Reliability evidence

Missing:

- Internal-consistency estimates (e.g. coefficient alpha/omega) per instrument
  version.
- Test–retest stability estimates.

Implication: Tier 1 reliability claims are blocked. (Note: internal
consistency alone does not establish validity; it is a precondition for
interpreting a score's precision.)

## Gap 3 — Validity evidence

Missing:

- Evidence for the proposed interpretation of each construct score.
- Evidence that items elicit the intended construct (e.g. structural/
  factor evidence, convergent/discriminant relations).

Implication: Tier 2 validity claims are blocked. Validity is a property of the
interpretation for a specific use, not of the test as an object (S-001).

## Gap 4 — Representative norming

Missing:

- A defined target population per language/culture context (`lt`, `en`).
- A sampling plan and a representative normative sample of sufficient size.
- Norm tables/percentiles.

Implication: Tier 3 norm-referenced claims (percentiles, "better than X%")
are blocked.

## Gap 5 — Organisational/high-stakes use

Missing:

- Job-analytic and criterion-related validity for any organisational use.
- Legal/compliance review (see O-006 in `docs/decisions.md`).

Implication: Tier 4 hiring/selection claims are blocked.

## Gap 6 — Data-protection and ethics baseline

Missing:

- Consent, retention, and access-control decisions (O-006, deferred to a
  dedicated legal/privacy review).

Implication: no compliance claims are permitted now; data collection for
validation must itself follow a later-approved data-governance plan.

## What closes these gaps (future tasks, not T-001)

1. Item authoring with provenance (O-002).
2. A defined validation study plan, including reliability and validity
   analyses (O-003).
3. A norming study plan with sampling (O-003).
4. A legal/privacy review establishing the data-governance baseline (O-006).

## Status

All gaps open. No claim above Tier 0 is currently permitted.
